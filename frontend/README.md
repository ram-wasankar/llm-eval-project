# LLM Observability Frontend

This Next.js app provides the dashboard for prompt logging, evaluation, and analysis.

## Local setup

1. Install dependencies:

```bash
npm install
```

2. Configure environment variables:

```bash
cp .env.local.example .env.local
```

Update `NEXT_PUBLIC_API_BASE_URL` in `.env.local` if your backend runs elsewhere.

3. Start the dev server:

```bash
npm run dev
```
